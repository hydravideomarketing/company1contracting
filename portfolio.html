📸 Add a Project Photo

To add a photo here, place your image file in the portfolio-images/ folder inside the website directory, then replace the .media-slot element in the HTML with an <img> tag pointing to your file.

<img src="portfolio-images/your-photo.jpg"
     alt="Project description"
     style="width:100%; height:100%; object-fit:cover; border-radius:8px;" />

▶️ Add a Project Video

To add a YouTube or Vimeo video, replace the .video-slot element with an iframe embed code from YouTube/Vimeo. Your video will appear directly in the grid.

<iframe width="100%" height="100%"
  src="https://www.youtube.com/embed/VIDEO_ID"
  frameborder="0" allowfullscreen></iframe>
